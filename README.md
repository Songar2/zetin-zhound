# Z-HOUND

ZETIN 4족보행 로봇 안내견 개발 현황 및 전장 연결 테스트 발표자료.

발표: https://songar2.github.io/zetin-zhound/

- F 키 또는 슬라이드 더블클릭: 발표 모드
- ← / →: 슬라이드 이동
- Esc: 전체 슬라이드 목록
- 전기 테스트 영상은 재생 버튼으로 재생

2026-10-28 업데이트: 원본 디자인과 V9 표지, CAD 2차 개발, 공유 Drive의 구조·재료 분석, 전기 테스트 사진 2장과 영상 2개를 반영한 27장 구성. 웹 영상은 H.264/AAC 사본이며 원본과 같은 길이입니다.
